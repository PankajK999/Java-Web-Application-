# Java-Web-Application-

A simple Java web application built using Java Servlets and deployed on Apache Tomcat. This project demonstrates the basic structure and deployment process of a Java web application.

🚀 Features
Java Servlet-based web application

Runs on Apache Tomcat

Maven-based project

Simple HTTP GET request handling

Easy to build and deploy as a WAR file

🛠️ Technologies Used
Java

Java Servlet

Apache Tomcat

Apache Maven

HTML

Git & GitHub
